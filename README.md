## 📖 Beginner's Guide: How to Add Shortcuts

To use Zoro88, you need to provide the path to the application or file. If you don't know how to do that, follow these simple steps to create a "Shortcut" (a link to your app) on Windows:

### 1. How to create a Shortcut for an App (e.g., Google Chrome)
1. Go to your **Desktop**.
2. Right-click on an empty space, select **New**, then **Shortcut**.
3. A window will open. Click **Browse...**
4. Find the app you want (e.g., Google Chrome) and select it, then click **OK**.
5. Click **Next**, give it a name (e.g., "Chrome"), and click **Finish**.
6. Now, open Zoro88, click **+ Add New Shortcut**, and in the "File Path" section, click **Browse** and select the shortcut you just made on your Desktop.

### 2. How to create a Shortcut for a Folder (e.g., Downloads)
1. Find the folder you want on your PC.
2. Right-click on the folder and select **Show more options** (on Windows 11) or just **Send to** (on Windows 10).
3. Select **Desktop (create shortcut)**.
4. Now, open Zoro88, click **+ Add New Shortcut**, and browse to select the shortcut from your Desktop.

### 3. How to create a Shortcut for a Website (e.g., YouTube)
1. Open your web browser (Chrome, Edge, etc.).
2. Go to the website you want (e.g., `youtube.com`).
3. Click and hold the **Lock icon** (or the small icon next to the URL) and **drag it** to your Desktop.
4. A file with the website's name will appear.
5. Open Zoro88, click **+ Add New Shortcut**, and browse to select this file.

## How to Use

1. Launch `ZORO DASHBOARD88`.
2. To add a new tool, click the **+ Add New Shortcut** button.
3. Enter a Name, browse for the File Path (using the methods above), and optionally choose an Image.
4. Click **Save**. Your tool is now ready to be launched with one click!

## System Controls

The left sidebar gives you instant control over your PC:
- **Shutdown / Restart:** Safely turn off or reboot your computer.
- **Close All Windows:** Force-closes all running apps (except Windows system processes).
- **Kill Top 10 Apps:** Identifies and kills the top 10 apps that are eating your RAM, instantly making your PC faster.
